# ✉️ Postcard School

A fun, interactive single-page guide that teaches you how to correctly address and stamp a postcard, for mail inside the US or to other countries.

**Open `postcard-guide.html` in any browser.** There's nothing to install, no frameworks and no API keys.

## What it does

- ✏️ **Practice postcard:** a to-scale 4″×6″ card with labeled zones (stamp, return address, message, recipient, barcode zone)
- ✅ **Check my postcard:** flags missing ZIPs, a misplaced country line, too little postage and more
- 🌍 **Domestic & international:** correctly formatted sample addresses for 17 countries
- 💲 **Postage & timing:** current stamp prices, stamp combos, size rules and delivery estimates
- 🧮 **Extras:** stamp calculator, postcard size checker and a 5-question quiz

## Updating prices

Open `postcard-guide.html` and edit the `RATES` block at the top of the `<script>`. Prices are in cents (65 = $0.65), and the whole page updates from those numbers.

> Always confirm current prices at [USPS.com](https://www.usps.com) or with the [USPS Postage Price Calculator](https://postcalc.usps.com).
